    \section{Краткое описание проекта}
    Создан Telegram-бот для изучения тем Второй мировой войны через диалог. Пользователь задает вопрос текстом или голосом, получает два ответа в стиле исторических деятелей, а затем видит подсказки, как продолжить тему. Проект ориентирован на понятное и быстрое объяснение сложных тем без перегрузки деталями.

    \section{Цель проекта}
    Сделать изучение истории более доступным и увлекательным за счет диалогового формата и контрастных позиций. Важно, чтобы пользователь не просто «получал информацию», а видел причины, контекст и последствия событий и мог продолжить изучение по логичному маршруту.

    \section{Актуальность и образовательная проблема}
    Темы Второй мировой войны объемные и часто воспринимаются как набор дат и фактов. Школьникам сложно быстро разобраться в сути события и связях между причинами и последствиями. Проект решает эту проблему через краткие структурированные ответы и последовательные подсказки для дальнейшего изучения.

    \section{Целевая аудитория}
    \begin{itemize}
        \item Ученики старших классов, которые готовятся к урокам и экзаменам.
        \item Учителя истории, которым нужен наглядный формат объяснения или демонстрации.
        \item Все, кто интересуется темой ВМВ и хочет быстро получить суть по конкретному вопросу.
    \end{itemize}

    \section{Задачи, которые мы решили}
    \begin{itemize}
        \item Сформулировали понятный формат ответа: тезис, причины, контекст, вывод, чтобы пользователь быстро понял суть.
        \item Реализовали два взгляда на один вопрос, чтобы показать разные позиции и усилить интерес.
        \item Добавили голосовые ответы, чтобы материал можно было воспринимать как краткое объяснение «на слух».
        \item Ввели подсказки «что спросить дальше», чтобы у пользователя был готовый маршрут изучения темы.
        \item Подготовили отдельный режим короткой дискуссии персонажей.
        \item Продумали несколько уровней сложности ответа для разных пользователей.
        \item Определили тематические рамки первого релиза (ключевые события и решения ВМВ).
        \item Подготовили сценарии использования, чтобы бот был удобен в учебных целях.
    \end{itemize}

    \section{Ключевые ценности продукта}
    \begin{itemize}
        \item Быстрое понимание сложных тем через структурированный ответ и уточнение непонятных моментов.
        \item Вовлечение в историю через формат «исторического батла» двух позиций.
        \item Управляемый маршрут изучения через список «следующих вопросов».
        \item Диалоговый формат вместо «лекции», чтобы ученик не терялся в большом объеме информации.
    \end{itemize}

    \section{Основной сценарий работы бота}
    \begin{enumerate}
        \item Пользователь задает вопрос текстом или голосом (например: «Почему началась битва за Сталинград?»).
        \item Бот отвечает двумя голосовыми сообщениями: от лица Сталина и от лица Черчилля.
        \item Дополнительно выводится текстовый блок «Что спросить дальше» с 3–5 предложениями, куда можно двигаться по теме.
        \item Пользователь выбирает следующий вопрос или меняет режим ответа (кратко/подробно, проще/академично, экзамен).
        \item Диалог продолжается, формируя цепочку связанных исторических тем.
    \end{enumerate}

    \section{Режимы ответа}
    \begin{itemize}
        \item «Кратко/подробно»: позволяет получить либо быстрый ответ, либо развернутое объяснение.
        \item «Проще/академично»: уровень сложности подбирается под подготовку пользователя.
        \item «Экзамен»: ответы формулируются так, чтобы помогать подготовке к проверочным работам.
    \end{itemize}

    \section{Режим «Исторический батл»}
    В отдельном режиме после двух ответов запускается короткая дискуссия персонажей. Каждый делает 1–2 реплики, которые помогают сопоставить аргументы и увидеть противоречия. Дискуссия остается образовательной и ограниченной по длине, чтобы не отвлекать от сути и не уходить в лишние детали.

    \section{Что реализовано в MVP}
    \begin{itemize}
        \item Прием текстовых и голосовых вопросов.
        \item Два ответа на один вопрос: от лица И. В. Сталина и У. Черчилля.
        \item Голосовые ответы и текстовые подсказки «что спросить дальше».
        \item Переключатели режимов: «коротко/подробно», «проще/академично», «экзамен».
        \item Режим «Исторический батл» с короткой дискуссией персонажей.
        \item Тематический охват первого релиза: ключевые события и решения Второй мировой войны.
        \item Возможность вести пользователя по теме через цепочку связанных вопросов.
    \end{itemize}

    \section{Образовательный эффект}
    Бот помогает быстро разобраться в теме и не перегрузиться деталями. Формат двух позиций развивает критическое мышление, а подсказки для следующего вопроса формируют последовательный маршрут изучения. Такой подход помогает запомнить не только факты, но и их взаимосвязи.

    \section{Ограничения текущей версии}
    \begin{itemize}
        \item Бот не заменяет учебник или учителя, а служит для быстрого объяснения и ориентации в теме.
        \item Дискуссия персонажей ограничена по длине, чтобы сохранять учебный формат.
        \item Тематика сосредоточена на ключевых событиях ВМВ, без ухода в другие исторические периоды.
